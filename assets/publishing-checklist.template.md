# 发布确认单

- [ ] 文章正文由作者审阅，真实经历由作者确认
- [ ] 核查事实、日期、数字和引用来源
- [ ] 标题与正文一致，≤25 字，不夸张、不仿冒官方
- [ ] 摘要不超过 120 字
- [ ] 图片版权、使用授权及隐私脱敏已核实
- [ ] 公众号后台粘贴后样式正确
- [ ] 手机端预览无乱码、溢出、丢图
- [ ] 公众号后台最终预览由作者确认
- [ ] 状态标记正确，未把“生成稿”说成“已发布”

## 品牌图片检查（v1.2）

- [ ] 默认品牌封面含同一个 3D 人物和原始 Logo /「小康新鲜事儿」字标
- [ ] 公众号名称与头像/Logo 准确无误，无自动捏造的二维码或认证标记
- [ ] 多种裁切比例下人物脸部、标题和字标完整可见
- [ ] 如换成其他用户的品牌，封面、正文图片、文字完全去掉旧品牌元素
- [ ] 确认个人品牌图片可用于此次传播范围；公开仓库传播需先确认
