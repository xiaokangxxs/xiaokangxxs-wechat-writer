# 使用指南与完整示例

## 标准共创

~~~text
使用 xiaokangxxs-wechat-writer 带我写一篇公众号文章。
严格按步骤提问，每一步等我确认后再继续。
~~~

正确的第一步是询问选题灵感/已有素材，而不是直接生成大量正文。热点与非热点分别按 SKILL.md 分支处理。

## 口述稿 L1 整理

~~~text
我已把内容口述转文字。请按 L1 保真整理，
只修逻辑衔接、错字、冗余，不要加入任何新事实。
~~~

L1 默认保真；L2 深度润色、L3 扩写必须得到作者明确授权。

## 封面与正文插图

~~~text
给这篇文章做封面和 2 张真正有帮助的配图。
handraw-style 风格指定 169，封面保留我的 3D IP 和真实 Logo。
正文图使用同一色盘，按文章段落锚点插入。
~~~

如果不提供编号，Skill 会基于文章思想、读者与画面隐喻动态推荐，而不是将“AI”固定映射到某个风格。

## 以其他品牌写作

~~~text
这篇使用我上传的新 Logo 与新 3D 人物，
公众号名叫 XX。不要使用小康新鲜事儿的素材。
~~~

用户级覆盖优先于默认配置；两个品牌资源绝不可混用。

## 发布包

- 作者确认的 Markdown 正文；
- 五种不同标题及正文依据，25 字以内；
- 120 字以内摘要；
- 公众号封面规范（推荐 2.35:1）；
- 正文配图锚点、alt、风格编号和提示词；
- 若图片工具真正完成了生图，则附实际文件；
- 排版和来源/授权核查清单。

实际用户确认、工具调用、生成图、公众号后台发布，不得由样稿或默认规则伪造。
