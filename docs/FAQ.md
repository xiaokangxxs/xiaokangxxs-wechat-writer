# FAQ / 常见问题

**可以一键生成整篇文章吗？**  
有演示模式，但真实作者创作默认分阶段确认，避免虚构本人经历。

**是否要求口述？**  
不要求；零散笔记、完整草稿和录音转写都支持。

**有没有去 AI 味？**  
默认 L1 保真编辑，删掉套话与重复，尽量保留作者真实语气。

**169 号风格是什么？**  
按已核验的上游索引，历史 169 对应 FH-015（彩铅日记），不是 FH-169。完整列表应从上游查询。

**没指定编号怎么办？**  
动态基于文章主题、受众和视觉隐喻选择；不能机械匹配关键词。

**所有图片都会带个人 IP 吗？**  
封面默认应使用授权的 3D 人物与真实 Logo；正文图取决于认知功能，流程图不需要强塞人物。缺素材则提示用户补齐。

**能直接发布到公众号吗？**  
不能默认。HTML 用于离线预览；真实公众号编辑器粘贴和发布需登录权限及手机复核。

**npx skills add 是 npm 发布吗？**  
不是。Skills CLI 读取 GitHub Skill。

**Github 首页 SVG 是之前生成的 PNG 吗？**  
不是。它们是用来清楚展示版式与配图逻辑的自有 SVG 演示图。真实图片需另行附文件或生成。

**会将资料上传出去吗？**  
本 Skill 自身无云端后端。宿主 Agent 若执行联网搜索或图像工具调用，其数据边界由用户选择的服务和权限决定。
