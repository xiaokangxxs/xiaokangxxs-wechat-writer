# 设计架构

这是 **协作写作 Agent Skill**，并非自动发文后台。

~~~text
用户输入：灵感 / 热点 / 文件 / 口述 / 原稿
                  │
             SKILL.md 路由
         ┌────────┴────────┐
         │                 │
     写作流程           事实/来源
   阶段 0–7           真实性 / 权限
         └────────┬────────┘
                  │
            内容审稿与标题
                  │
         ┌────────┴────────┐
      视觉引擎           微信排版
   handraw + 品牌       Markdown / HTML
         └────────┬────────┘
                  │
         发布前质检与复盘（可选）
~~~

## 十阶段

0 作者档案；1 灵感；2 选题；3 授权素材；4 大纲；5 口述/草稿；
6 L1/L2/L3 编辑；7 事实与标题；8 发布包/配图；9 经授权的复盘沉淀。

默认逐步确认。可以在用户明确要求下选择快速整理或演示模式，禁止假装已经获得作者批准。

## 数据边界
文字是用户观点；外部事实要核查；品牌素材只用授权文件。没有知识库访问权限时不声称检索完成；没有图像工具时不声称完成生图。

## 视觉子流程
提炼中心矛盾 → 构思一个隐喻 → 风格编号解析/动态选风格 →
正文图价值判断 → 品牌原图合成 → 裁切/手机尺寸检查 →
按锚点写入 Markdown 和离线 HTML。

不为了漂亮图片擅自改变作者原稿。
