# 选题与张力：真实冲突，而非标题党

## 分支 A：热点

1. 先问有没有用户本人希望写的热点。有则优先围绕该话题。
2. 没有时，确认作者领域和读者后用可用的网络检索能力寻找近期讨论。新闻来源、官方发布、行业社区/社交讨论交叉核查，不要用未经证实的单条帖子当事实。
3. 每个热点拆成：事实是什么、普通文章常见角度、被忽略的问题、可支撑的新角度、适合作者的依据。
4. 汇总 3–5 条**有具体切入点**的候选，列出证据、风险、可能的读者获得感。
5. 若无法联网，明确说明无法确认实时热度，只给常青角度或请用户提供热点链接。

不要说“全网没人写”或“唯一真相”；可以说“在本次检索的样本中，这个角度较少出现”。

## 分支 B：非热点

严格依次问两个问题：
- “你最近有没有发现一个大家都信、但你觉得并不对的观点？或做了什么事，结果和预期相反？”
- “你希望读者看完得到什么：认知刷新、具体做法，还是情绪共鸣？”

把回答加工成选题卡，包含：普通看法 → 反常识判断 → 一个具体场景 → 核心证据 → 读者收获；不凭空塞数字。有数据就写数据，没有就用可核验的场景，别为了“有数字”杜撰百分比。

## 评价维度（每项 0、1、2 分）

- 痛点：读者是否正在经历？
- 张力：是否有可解释的认知落差？
- 证据：事实、经历或可观察案例是否能支撑？
- 独特：是否有作者自己的观察/资料？
- 可兑现：正文是否能回答标题的问题？

满分 10 分。评分仅用于比较候选，不是客观预测流量。证据为 0 的选题不能作为事实型成稿进入下一步。

## 候选输出格式

**选题** / **一句话观点** / **新角度在哪里** / **读者收获** / **支撑素材** / **待核实** / **评分**。输出完停下来等待选择。
