# 封面图与正文配图规则

## 品牌视觉入口

**生成封面图前必读**：[品牌视觉策略](brand-visual-policy.md)，从 `../assets/brand-profile.json` 找到当期品牌素材。默认使用「小康新鲜事儿」的 3D 形象、Logo、字标、品牌蓝；封面必须出现人物和真实品牌标识（除非用户显式要求关闭）。新用户可提供专属素材覆盖，禁止把旧品牌人物混入新品牌。

## handraw-style 选风格路由（v1.3）

封面与正文插图默认启用 [handraw 集成](handraw-integration.md)，用户指定风格或主题色时严格沿用。没有指定时结合全文、视觉隐喻与受众动态选最适合的编号并写明理由，非机械套用固定号。实际生成过程中保持**原品牌角色与 Logo 的精确身份**；需要上游参考图时应确认资源存在并真实传给图像工具。

## 总原则

图片不是为了“显得完整”，而是为了**提高点击意愿、帮助理解、改善阅读节奏**。如果文章本身以观点推进为主、信息密度高而不依赖视觉解释，可以不配图。

始终遵守：

- 先有文章核心观点，再决定是否出图；不要为了配图反过来改文章逻辑。
- 图片必须与正文内容一一对应；不能只给“科技感”“高级感”这类空泛要求。
- 不得复制明显受版权保护的海报、封面、UI 截图或品牌宣传图；需要品牌感时，做“相似气质”而非直接复刻。
- 人物、聊天记录、后台页面、用户数据截图要优先考虑脱敏和授权。
- 如果当前环境没有图像能力，就输出结构化 brief 和 prompt，不假装已经生成图片。

## 什么时候建议配图

适合配图的情况：

1. 开头需要建立情境，例如“桌面、多工具、工作流混乱”等场景。
2. 文中有抽象概念，读者看文字容易疲劳，比如“完成标准”“决策成本”“返工循环”。
3. 有明确结构或方法论，适合做成简洁示意图、流程图或卡片图。
4. 文章较长，段落之间需要节奏变化。
5. 公众号封面需要更好的点击率或品牌统一感。

不建议硬配图的情况：

1. 文章本身很短，配图会打断节奏。
2. 正文没有明确画面或结构，只能生成空泛装饰图。
3. 涉及不适合公开的真实界面、截图、隐私信息。
4. 图片风格会误导读者，把观点文章做成营销广告图。

## 数量建议

- **封面图：1 张必选**（至少输出 brief；若用户需要且工具可用则生成成品）。默认封面须包含启用品牌的 3D IP（如已提供）与原始 Logo / 公众号名称。
- **正文配图：0–4 张为宜**。通常 1200–2500 字文章配 1–3 张即可。
- 每隔 400–900 字可评估是否需要一张图，但不要机械按字数插图。

## 封面图规则

### 目标

封面图主要承担三件事：

1. 在公众号列表中建立第一眼识别；
2. 传达文章核心冲突或情绪；
3. 与作者品牌或长期栏目保持一致。

### 封面 brief 必填项

- 文章标题 / 暂定标题
- 文章一句话核心冲突
- 目标读者
- 视觉风格（写实 / 扁平插画 / 轻拟物 / 信息卡片 / 手绘等）
- 画面主体
- 构图与留白
- 主色 / 辅色
- 是否上字、上什么字
- 禁忌元素
- 用途备注（公众号封面、头图、跨平台复用）

### 设计规则

- 默认优先简洁、高级、移动端可识别。避免堆小元素和过多文字。
- 若加字，建议只放 1 句短文案，通常不超过 12 个汉字。
- 标题较长时，封面不要全文复写标题；可以提炼一句冲突感更强的短句。
- 留出安全区，避免主体或文字贴边，以适应公众号列表裁切。
- **默认必须包含品牌 3D 人物 + Logo/公众号字标**，同时主标题和封面画面仍须突出文章本身；Logo 使用原图合成、不要让图片模型乱画；人物保留关键面容、服装识别特征。
- 默认给 1 个主方案，必要时补 1 个备选方案。

## 正文配图规则

### 插图类型

根据内容选择其中一种或两种，不要混太多风格：

1. **情境图**：用于开头建立阅读氛围；
2. **概念示意图**：把抽象观点变成可视化关系；
3. **清单卡片图**：把结论做成 3–5 条可扫读卡片；
4. **流程图 / 结构图**：展示步骤、循环或对比；
5. **数据图**：仅在有真实数据时使用，不能编造图表。

### 插入位置判断

优先在以下位置考虑插图：

- 标题后首屏下方：开场情境图；
- 第一处核心转折前后：帮助读者抓住主观点；
- 方法论或清单出现处：做成结构卡片图；
- 结尾前：如有必要，用总结卡片收束。

### 每张图都要输出这 6 项

1. 插入位置（位于哪一节、哪一段之后）；
2. 图片目的（帮助理解 / 建立情境 / 节奏变化 / 传播摘录）；
3. 画面内容；
4. 风格与配色；
5. 替代文本（alt text）；
6. 可直接用于图像工具的提示词。

## 建议输出格式

### 封面图

- 方案名
- 使用场景
- 画面描述
- 短文案（可选）
- 提示词
- 负面约束 / 禁忌

### 正文配图

按编号列出：图 1 / 图 2 / 图 3 …

- 插入位置
- 关联段落/标题
- 图片目的
- 画面 brief
- 提示词
- 替代文本

## 配图写作协同规则

- 文章未最终定稿前，不要锁定太细的插图描述；避免文章一改，所有图都要推翻。
- 文章定稿后再出图最稳妥；若要边写边出图，必须明确“可能随文稿调整”。
- 如果用户要求“适当位置自动生成配图”，先输出配图计划，再按计划逐张生成。
- 若同一篇文章存在封面图与插图，应尽量保持统一视觉语言、主色和质感。正文插图不强制每张出现 IP；可按需使用小角标。
